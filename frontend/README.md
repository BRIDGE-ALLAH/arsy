# ARSY Frontend

The frontend is a pnpm workspace with two independently deployable Next.js App Router apps.

- `apps/console`: customer cloud management console (scaffold only; no resource actions are available yet).
- `apps/website`: public ARSY landing page.

## Toolchain
- Node.js 26 LTS (see `../.node-version` and `.nvmrc`).
- pnpm 12.19.0 (pinned in the workspace manifest).
- Next.js 16.4.6 and React 19.2.0.

## Install and run

From this directory, run `pnpm install`, then `pnpm dev:console` or `pnpm dev:website`.

## Checks

Run `pnpm lint`, `pnpm typecheck`, and `pnpm build`. The workspace lockfile is generated by `pnpm install` and must be committed when dependencies are intentionally updated.

## Security
- Backend authorization is authoritative; hiding a frontend action is not security.
- Never store provider credentials or long-lived privileged tokens in browser storage.
- Use server components for server-rendered data and client components only for interactive state.
- Connect through a typed API client once the Control Plane API contract is committed.

These apps are scaffolds, not a finished console or commercial website.
